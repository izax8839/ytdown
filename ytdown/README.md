# 🎬 YouTube 미디어 다운로더 (동영상 & 고음질 음원)

YouTube 영상을 고화질로 다운로드하거나, 배경음악/음원만 최고음질(MP3 320kbps)로 추출하여 다운로드할 수 있는 직관적인 데스크톱 GUI 프로그램입니다.

---

## 🌟 주요 기능

### 1. 🎵 음원만 다운로드 (Music / Audio Only)
- **다양한 오디오 포맷 지원**: `MP3`, `M4A` (Apple 고음질), `FLAC` (무손실), `WAV` (비압축 원음), `OPUS`
- **음질(비트레이트) 선택**: 최고음질(320kbps), 고음질(256kbps), 표준음질(192kbps), 일반음질(128kbps)
- **앨범 아트 & 메타데이터 자동 삽입**: YouTube 영상 썸네일을 앨범 커버로 자동 등록하고 가수, 제목 등 ID3 태그를 기록합니다.

### 2. 🎬 동영상 다운로드 (Video)
- **고화질 해상도 선택**: 최고화질(원본 해상도 자동 선택 - 4K/2K/1080p 지원), 4K (2160p), 2K (1440p), Full HD (1080p), HD (720p), SD (480p)
- **비디오 포맷 지원**: `MP4` (호환성 최고), `MKV`
- **자막 다운로드 옵션**: 한국어/영어 자막이 있는 경우 비디오 파일에 포함 가능

### 3. ⚡ 사용자 편의 기능
- **영상 정보 미리보기**: YouTube 링크를 입력하면 썸네일 이미지, 제목, 채널명, 재생시간, 조회수를 즉시 확인
- **재생목록(Playlist) 지원**: 재생목록 링크 감지 시 단일 영상만 받을지, 재생목록 전체를 순서대로 받을지 선택 가능
- **클립보드 간편 붙여넣기**: 버튼 하나로 복사한 링크를 즉시 붙여넣고 분석
- **실시간 진행률 표시**: 다운로드 속도(MB/s), 남은 시간(초), 다운로드 용량, 퍼센트(%) 실시간 표시
- **원클릭 폴더 열기**: 다운로드가 끝나면 바로 저장 폴더를 열어 파일 확인 가능

---

## 🚀 실행 방법

### 방법 1. 간편 실행 (가장 추천)
폴더 안의 **`실행하기.bat`** 파일을 더블 클릭하면 바로 GUI 프로그램 창이 실행됩니다.

### 방법 2. 바탕화면 바로가기 만들기
**`바탕화면_바로가기_만들기.bat`**을 더블 클릭하면 Windows 바탕화면에 **'YouTube 미디어 다운로더'** 아이콘이 생성되어 언제든지 편리하게 실행할 수 있습니다.

### 방법 3. 명령 프롬프트(CLI)에서 실행
터미널이나 명령 프롬프트에서 직접 실행할 수도 있습니다:
```bash
# GUI 실행
python app.py

# CLI 음원 다운로드 (MP3 320k)
python cli.py -u "https://www.youtube.com/watch?v=..." -m audio -f mp3 -q 320

# CLI 동영상 다운로드 (1080p MP4)
python cli.py -u "https://www.youtube.com/watch?v=..." -m video -f mp4 -q 1080
```

## 📁 다운로드 파일 저장 위치
- 기본 저장 경로: `내 PC > 다운로드 > YouTube_Downloads` (`%USERPROFILE%\Downloads\YouTube_Downloads`)
- 프로그램 내에서 언제든지 **[📁 변경...]** 버튼을 눌러 원하는 폴더로 변경할 수 있습니다.
